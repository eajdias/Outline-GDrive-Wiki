# Template de COMUNICADO / POLÍTICA no padrão de qualidade

> Como usar: para avisos, políticas, regras e manuais de conduta. Sem resumo rápido,
> sem troubleshooting, sem passos numerados (salvo roteiro de ação). O essencial
> — o quê, quem afeta, desde quando — nas 3 primeiras linhas. Frontmatter: preserve
> o original byte a byte (§2 do STYLE-GUIDE).

```markdown
> Dono: <time/área> · Revisado em: <AAAA-MM> · Vale para: <escopo/vigência>.

## 🎯 Objetivo

<O que este documento determina ou comunica, em 1-2 frases.>

## 👥 Quem é afetado

- <público 1>
- <público 2>

## 📌 Regras

- **<Regra 1>:** <detalhe>.
- **<Regra 2>:** <detalhe>.

:::warning
<Exceção, penalidade ou ponto inegociável.>
:::

## ✅ Como agir (opcional — só se houver roteiro)

- <ação 1>
- <ação 2>

## Referências

- [Rótulo descritivo](https://url-completa)
```
