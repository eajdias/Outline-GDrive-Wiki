Página terceira (exemplo)

Esta página simula um site qualquer usando o chat via snippet.

  1. Procure a bolha verde no canto inferior direito.
  2. Clique nela: o painel do chat abre num iframe servido pelo chat.
  3. Pergunte algo do acervo, ex.: "Como configurar o acesso VPN?"

Para origem realmente cruzada, sirva esta página noutra porta (python -m http.server 8099 --directory apps/chat/public) e abra http://127.0.0.1:8099/embed-demo.html.
